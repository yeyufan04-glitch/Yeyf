# 3 分钟演示脚本

1. 从“案件总览”开始：说明系统没有给出虚构风险分，而是直接显示自动流转为何被拦截，以及人工只需处理哪两项例外。
2. 进入“单证事实”：依次点击合同、发票、提单、报关回执和付款指令，强调客户材料、外部独立证据和银行内部证据分层。
3. 进入“交易证据”：点击“本批实际装运数量”，展示 800 件独立证据与 1,000 件客户材料之间的冲突。
4. 进入“可信执行”：依次切换 C、A、V。指出分批履约语义解释样本不足，“发票笔误”为无支持 Claim，Policy Shield 禁止自动汇款。
5. 进入“可信凭证”：下载 JSON，说明几个月后仍可还原模型、规则、证据与动作边界。
6. 进入“人工处置”：勾选三项确认，生成补正请求并保持付款暂停。
7. 最后打开“规则与来源”：主动说明普通进口汇款不直接适用 UCP 600/ISBP 821，监管依据、开放标准和产品策略不能混为一谈。
